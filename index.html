使用教學 · QUICK START GUIDE

01 / 設定

選擇賽道、音效、計時模式與車手。倒數模式可設定專注時間、休息時間及循環數；也能用「自訂循環序列」建立不同長度的專注與休息區段。

02 / 開始與暫停

按 START 開始，PAUSE 暫停，RESUME 繼續。RESET 會清除本次尚未保存的進度；FINISH 會保存已完成的專注時間。

03 / 正計時與圈速

正計時會累積時間並依賽道設定切分圈速。賽道動畫會依目前圈速進度移動車輛，並記錄最快圈。

04 / 統計與紀錄

圖表可切換日、週、月；個人紀錄會計算總專注、最佳單次、最佳單日及連續專注天數。紀錄儲存在此瀏覽器。

05 / 設定中心

可調整預設時間、音效、完成提示、畫面密度與啟動時顯示方式。設定會保存在本機。

06 / 匯出備份

CSV 適合試算表；JSON 適合完整備份與日後匯入其他程式。請定期匯出，避免清除瀏覽器資料時遺失。

鍵盤快捷鍵：Space 開始 / 暫停、R 重設、F 全螢幕、? 開啟教學。快捷鍵在輸入欄位中不會觸發。
